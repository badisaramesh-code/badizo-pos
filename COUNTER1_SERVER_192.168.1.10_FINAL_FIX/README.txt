Run this package only on Counter1.

1. Extract the ZIP.
2. Double-click RUN_COUNTER1_FIX.bat.
3. After SUCCESS, use the new desktop shortcut named Badizo Counter1.

This shortcut opens the server directly in a normal browser window. It prevents
the Counter1 computer from starting a second local server on port 5000 and keeps
the billing screen open when the print preview is closed.

Correct server: 192.168.1.10:5000
Login: counter1
