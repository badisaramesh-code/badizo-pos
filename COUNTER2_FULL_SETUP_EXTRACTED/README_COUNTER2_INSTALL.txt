Badizo Counter2 Install Package

Server IP:
192.168.1.8

Copy this full folder to Counter2 system.

On Counter2 system, double-click:
setup-counter2-one-click.bat

Important:
Do not run the bat file directly from WinRAR/zip preview.
First extract the full zip/folder, then run setup-counter2-one-click.bat from the extracted folder.

The setup will:
- Check http://192.168.1.8:3000
- Check http://192.168.1.8:5000/api/health
- Install Badizo
- Create Counter login mode config
- Open Badizo app

Do not install MySQL/backend/source code on Counter2.
Counter2 only connects to the server.
