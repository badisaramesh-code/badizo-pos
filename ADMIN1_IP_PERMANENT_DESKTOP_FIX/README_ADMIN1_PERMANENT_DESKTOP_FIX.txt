Badizo Admin1 IP Permanent Desktop Fix

Use this package on the Admin1 system only.

Steps:
1. Right-click ADMIN1_IP_PERMANENT_DESKTOP_FIX.zip and choose Extract All.
2. Open the extracted ADMIN1_IP_PERMANENT_DESKTOP_FIX folder.
3. Double-click RUN_ADMIN1_PERMANENT_FIX.bat.
4. After it finishes, open Badizo from the normal desktop shortcut:
   Badizo
