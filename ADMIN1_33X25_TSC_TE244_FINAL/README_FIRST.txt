BADIZO ADMIN1 - TSC TE244 - 33 x 25 STICKER SETUP

This package is only for the Admin1 computer (expected IP 192.168.1.7).

1. Extract the ZIP completely.
2. Connect and switch on the TSC TE244 printer.
3. Double-click INSTALL_ADMIN1_33X25.bat.
4. Accept the Administrator permission prompt.
5. After SUCCESS, open only the desktop shortcut: Badizo Admin1

Configured values:
- Badizo server: 192.168.1.10:5000
- Login: admin1
- Printer: TSC TE244
- Windows share: TSC-244-2
- Sticker: 33 x 25 mm, two stickers per row
- Server printer path: \\192.168.1.7\TSC-244-2

If the setup warns that Admin1 IP is not 192.168.1.7, note the detected IP.
The server printer mapping must be changed to that detected fixed IP before printing.
