Counter1 Direct Browser Fix
===========================

Use this if the Badizo app still opens:
  http://192.168.1.14:3000

Open Counter1 using the correct server:
  http://192.168.1.9:5000?loginMode=counter&loginUser=counter1

Steps on Counter1:
1. Double-click OPEN_COUNTER1_5000_BROWSER.bat
2. If it opens correctly, double-click CREATE_COUNTER1_5000_DESKTOP_SHORTCUT.bat
3. Use "Badizo Counter1 5000" from Desktop.

Do not use the old Badizo app icon until it is uninstalled/reinstalled or its old config is removed.
