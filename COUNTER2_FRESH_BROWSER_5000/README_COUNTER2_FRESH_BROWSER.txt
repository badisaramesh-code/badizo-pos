Counter2 fresh browser launcher

Use OPEN_COUNTER2_FRESH_BROWSER.bat on Counter2.

This opens Badizo Counter2 on:
http://192.168.1.9:5000?loginMode=counter&loginUser=counter2

It uses a separate Chrome profile:
%LOCALAPPDATA%\BadizoCounter2ChromeProfile

If Counter2 behaves slowly or old code appears, run:
RESET_COUNTER2_BROWSER_CACHE.bat

Do not use old Badizo app icons or any shortcut that opens port 3000.
